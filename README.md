# 뽀글팡 아일랜드

거품을 불어 뽀구리를 가두고, 톡 터뜨려 과일로 바꾸는 버블보블 스타일 브라우저 게임이에요.

## 바로 하기

https://yjyeom1545.github.io/ppogeulpang-island/

PC와 모바일 브라우저에서 모두 실행돼요. 모바일에서는 화면에 터치 버튼이 나와요.

## 조작법

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ | 점프 |
| ↓ | 발판 아래로 내려가기 |
| Space | 거품 쏘기 |
| P | 일시정지 |

## 게임 구성

- 전체 10라운드, 5라운드와 10라운드는 보스전 (왕뽀구리, 불꽃 뽀구리 대왕)
- 난이도 4단계: 쉬움 · 보통 · 어려움 · 지옥
- 거품 4개 이상 연쇄로 터뜨리면 피버 타임 (점수 2배)
- 3라운드부터 움직이는 발판 등장
- 닉네임 설정, 난이도별 개인 최고점 저장

온라인 랭킹(명예의 전당)은 claude.ai 아티팩트 링크로 열었을 때만 동작해요. 이 페이지에서는 개인 최고점만 브라우저에 저장돼요.

## 파일

`index.html` 한 파일에 게임 전체가 들어 있어요. 내려받아 더블클릭해도 PC 브라우저에서 바로 실행돼요.
